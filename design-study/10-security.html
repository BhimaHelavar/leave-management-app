Security and privacy design

Security is a design property, not a feature added at the end. The LMS holds personal and sometimes health-related data (sick leave), so it is a good case study.

Why hiding a button is not securityAngular guards improve usability. Anyone can call the API with curl, so every rule is enforced again on the server.

Entra ID uses authorization code flow with PKCE (MSAL): the SPA has no client secret.

Dev mode is not securityAuth:Mode=Dev lets anyone pick any demo user. The startup check allows it only in Development or Demo, and the signing key must be 32+ characters.

Audit: BR-07 made real

  • Every apply, approve, reject, cancel, balance change and refusal writes an AuditEvent in the same transaction as the change.
  • Row holds ids and values ({from:Pending,to:Approved}), never names, emails or free text.
  • Immutable in 3 layers: (1) permissions (INSERT, SELECT only); (2) a trigger that throws on UPDATE/DELETE; (3) later, a hash chain for tamper evidence.
