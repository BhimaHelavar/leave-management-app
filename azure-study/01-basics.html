Azure basics: the words everyone uses

Azure is a rented data centre. You do not buy servers; you create resources and pay for what they use. First learn how Azure organises them.

The hierarchy

Microsoft Entra tenant      = your organisation's identity directory (users, apps)
 └─ Subscription            = the billing account. Costs and limits live here
     └─ Resource group      = a folder of resources that share a life (create/delete together)
         └─ Resource        = one thing: a web app, a database, a key vault…
WordMeaningLMS example
TenantThe identity directory (Entra ID). Users and app registrations live here.Your personal Microsoft account creates a default tenant
SubscriptionWhere the bill goes. A free account gives credit plus always-free amounts.One subscription for the demo
Resource groupA folder. Delete the group, everything inside goes.rg-lms-demo
RegionThe data-centre location. Price, features and free quota differ per region.South India (Chennai), fall back to Central India, then Southeast Asia
ResourceOne service instance.lms-api-xyz (web app), lms-sql-xyz (SQL server)
ARMAzure Resource Manager: the one API behind the portal, CLI and Bicep.Every command you run ends up as an ARM call
Why resource groups matterPut the whole LMS demo in one group. At the end of the project one command removes everything and stops all cost: az group delete -n rg-lms-demo.

Free account: what to expect

  • New accounts usually get a time-limited credit plus a list of "always free" services. The exact amounts change. Read your own account page; I could not open the free-account page when writing this, so I give no numbers.
  • The LMS plan deliberately uses services that have a free tier of their own: Static Web Apps Free, App Service F1, and the Azure SQL free offer.
  • Free tiers have limits and usually no SLA (no uptime promise). That is fine for a portfolio demo and worth saying in an interview.

Step 1: install the tools and sign in

winget install -e --id Microsoft.AzureCLI
az --version
az login
az account show --query "{name:name, id:id}" -o table
az account list -o table
# if you have several subscriptions:
az account set --subscription "<subscription name or id>"

Commands in these notes are written for PowerShell. Variables look like $RG. In Command Prompt use set RG=... and %RG%.

Step 2: create the resource group (and test the region)

$RG  = "rg-lms-demo"
$LOC = "southindia"          # change if a later step says the free tier is not offered here
az group create -n $RG -l $LOC
az provider register --namespace Microsoft.Web
az provider register --namespace Microsoft.Sql
az provider register --namespace Microsoft.Insights
az provider show -n Microsoft.Web --query registrationState -o tsv
What is a resource provider?Each service family (Web, Sql, Insights…) is a provider that must be "registered" on your subscription once. New subscriptions sometimes fail with MissingSubscriptionRegistration. Registering fixes it.

Step 3: put a budget on it (do this before anything else)

Spec T-02 asks for a budget of about 1 USD a month with alerts at 50 % and 100 % and a forecast alert. A budget only sends emails; it does not stop spending. Brand-new subscriptions can take up to 48 hours before budgets can be created, so try it early.

  1. Portal → Cost Management + Billing → Budgets → Add.
  2. Scope: the subscription (or the resource group). Amount: the smallest value your currency allows.
  3. Alerts: 50 % actual, 100 % actual, 100 % forecasted. Add your email.
  4. Create an action group and press Test to prove the email arrives.

Check yourself

What happens when you delete a resource group?
Deleting the group deletes everything in it. That is why one group per environment is a good habit.
Does a budget stop a service when the amount is reached?
A budget notifies. To stop spending you delete or stop the resource (or use an automation triggered by the alert).
