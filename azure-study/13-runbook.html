Troubleshooting decision tree

Site shows config error?      → config.json missing/HTML/trailing slash
Login list empty or fails?    → open DevTools Network
   CORS error                 → Cors__AllowedOrigin must equal the page origin
   CSP error                  → staticwebapp.config.json connect-src
   500 / 503                  → az webapp log tail (startup exception?)
   "Invalid object name"      → tables not created (Part C)
   SQL login/firewall error   → firewall rules, connection string
   Very slow first call       → cold start (F1) or database resuming. Normal on free tiers
